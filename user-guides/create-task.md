# How to Create a Task in CloudDesk

## Purpose

This guide explains how to create and save a task within an existing CloudDesk project.

## Requirements

- Signed into CloudDesk.

## Steps

1. Sign in to the CloudDesk app.

2. Open an existing project.

3. Select **Add Task**.

4. Enter a task title (required).

5. Enter a description (optional).

6. Select an assignee (optional).

7. Choose a due date (optional).

8. Select **Save Task**.

## Expected Result

The task appears in the project's task list.
